# XiaoWan Agent
XiaoWan Agent, local web AI assistant powered by DeepSeek API.
Supports PC automation and Android ADB control with multi-model selection.

## Features
- Multi-model selector for DeepSeek
- Code generation & creation mode
- PC automation control
- Android device control via ADB
- Clean web UI
